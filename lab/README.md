# The deliberation lab (experiment)

**Status:** built 2026-10-03 and proven end to end **on a fake model only**. Nothing here has met a real
LLM yet. · **Design:** [deliberation-lab.md](../docs/research/dspy/deliberation-lab.md),
[DL-264](../docs/design-log.md), and [the DSPy 3.4 notes](../docs/research/dspy/practitioner-notes-3.4.md).

**What it answers.** Given a prompt variant and a set of cases, do the three deliberators **understand**
the evidence, **use** it, and decide on **market evidence**? It does not just deliver a verdict.

**Ground rules** (operator, 2026-10-03):

- This is an experiment, deliberately outside the repo's CI gates.
- **It must not break anything that exists.** It changes no production file, no root config, and not
  `uv.lock`. It writes nothing to the graph, the bus, the fleet or the broker. The repo's
  `ruff check .` and `ruff format --check .` still pass, using `lab/pyproject.toml`.
- It runs in the repo's own environment, with DSPy from the existing `optimizer` extra (3.4.0,
  already locked).

## What is in it

| Piece | File | What it does |
| --- | --- | --- |
| Cases | `deliberation/scenarios.py`, `cases.py` → `cases/synthetic/*.json` | Eight named market situations. Each is pushed through the **fleet's own** scanner, analyst and PM (with the pack's overrides), then the **production renderer** `build_veto_context`. The packet is exactly what the deliberators would see |
| Book I, the dictionary | `book/entries.py`, `dictionary.py` → `book/generated/dictionary.md` | 90 keys defined from the code. The **bands are generated by probing the scorers**, so they cannot drift from the code. `book/coverage.py` proves every key in the packets is either defined or structural (161 = 90 + 71) |
| Book III, house rules | `book/house_rules.py` | 11 rules with citations, and falsifier patterns for false statements |
| Typed outputs | `outputs.py` | `Brief` (readings, gaps, case) and `Ruling` (own readings, decisive keys, market conditions, accepted, rejected, ruling, rationale) |
| Decision code, Tier A | `laws.py` | DEC-FORM-01..06, checked by code. The feedback quotes the dictionary |
| The trio | `program.py` | DSPy signatures. The book goes in the **system message**, through a custom adapter. Topologies **T0** (sequential debate, N rounds) and **T2** (independent briefs in parallel, then a deciding judge). Instruction arms `production` and `lab` |
| Engines | `engines.py` | A deterministic fake ($0), or real `dspy.LM` (Anthropic / OpenAI). **No temperature is ever sent**, because Opus 5.5 rejects it |
| Runner | `run.py` | Each seat gets **one form-law retry** (our own loop, not `dspy.Refine`). Every real run is costed and refused without `--max-usd`. Writes `results.json` + `report.md` |
| Compare | `compare.py` | Several runs side by side |

## Run it

From the repo root:

```bash
# 1. rebuild the cases and the dictionary (deterministic, $0)
PYTHONPATH=. uv run --frozen --extra optimizer python -m lab.deliberation.cases
PYTHONPATH=. uv run --frozen --extra optimizer python -m lab.deliberation.book.dictionary
PYTHONPATH=. uv run --frozen --extra optimizer python -m lab.deliberation.book.coverage

# 2. prove the machinery on the fake model ($0)
PYTHONPATH=. uv run --frozen --extra optimizer python -m lab.deliberation.run \
    --variant lab/deliberation/variants/lab_t2_book.json --engine fake --out /tmp/lab/fake

# 3. real models (needs ANTHROPIC_API_KEY in the shell; refuses without a cap)
PYTHONPATH=. uv run --frozen --extra optimizer python -m lab.deliberation.run \
    --variant lab/deliberation/variants/lab_t2_book.json --engine real --max-usd 5 --out /tmp/lab/lab_t2_book
PYTHONPATH=. uv run --frozen --extra optimizer python -m lab.deliberation.compare /tmp/lab/<run> /tmp/lab/<run> ...
```

Use `--cases falling_knife,value_trap` to run a subset first. That is the cheapest way to see the
first real numbers.

## The variants (`deliberation/variants/`)

| Variant | Question it answers | Estimated cost, 8 cases |
| --- | --- | --- |
| `today_prod_t0_opus5` | How does today's set-up read the evidence? (production prompts, no book, 2-round debate, Opus 5) | printed before the run |
| `prod_t0_nobook` | What does the model change alone do (Opus 5.5)? | printed |
| `prod_t0_book` | What does the **book alone** add? | printed |
| `lab_t0_book` | What do lab instructions add, on today's debate shape? | printed |
| `lab_t2_book` | The operator's design: independent briefs and a deciding judge | ~$2.65 expected, $16.83 upper bound |

🪤 **The `production` instruction arm is production's role text inside the lab's typed output
contract**, not a byte-for-byte replay. In particular, production's judge prompt asks for a one-line
JSON answer, and here it gets the typed `Ruling` instead. A byte-parity baseline is a later step.

## What the fake run proves, and what it does not

**[measured 2026-10-03, fake engine, `lab_t2_book`]** 48 calls (8 cases × 3 seats × 2 attempts). The
first attempts broke the form laws 67 times, by design of the fake:

| Clause | Count | What it caught |
| --- | --- | --- |
| DEC-FORM-01 | 16 | rounded values |
| DEC-FORM-02 | 27 | `pe` read as a ratio; a contrarian score read backwards |
| DEC-FORM-03 | 8 | a process-only basis |
| DEC-FORM-05 | 8 | an uphold that did not answer the other side |
| DEC-FORM-06 | 8 | "revise blocks", "calendar days" |

All 67 were corrected on the single retry. On `prod_t0_book` with the JSON adapter: 80 calls, 101 → 0.

**It proves** that cases, book, adapter, both topologies, both adapters, the checker, the retry, the
cost ledger, the spend refusal and the report all work together. **It proves nothing about the real
expert.** The fake's rulings are scripted.

## Already learned from the synthetic cases (real code, no LLM)

- **Upstream gates already stop the crudest cases.** A plain downtrend and a falling-price value trap
  are dropped by the scanner's minimum relative strength. A strongly negative news day drives the
  sentiment pillar to 0 and the analyst's confidence below its 0.60 floor. The scenarios were tuned so
  that each one reaches the referee.
- **The falling knife is bought.** RSI 24, 20 % below the 200-day average, relative strength −15 points:
  the composite is 0.532, which gives confidence 0.619, which clears the 0.60 floor. The contrarian
  sub-scores (RSI 80, stochastic 80, Williams 75, Bollinger 75) lift it.
- **Its reward/risk is 0.57 and the gate PASSES.** The target is 2.66 % against a 4.64 % stop, because
  the gate is disclosure-only at threshold 0.
- **One packet carries two different `relative_strength` values** (−15 percentage points, and 0.579 as
  a fraction), plus `pe=60` beside `peBasicExclExtraTTM=19`.
